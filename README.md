\# Home Loan Approval Prediction



An AI/ML project that predicts whether a home loan application will be approved or not using Machine Learning algorithms.



\## 📌 Project Overview



This project analyzes applicant details such as:



\- Gender

\- Marital Status

\- Education

\- Income

\- Loan Amount

\- Credit History

\- Employment Status



and predicts loan approval status.



The model is trained on historical loan application data using Python and Machine Learning techniques.
